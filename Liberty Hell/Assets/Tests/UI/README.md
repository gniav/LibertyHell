# Проверка интерфейса

Откройте `Assets/Tests/UI/GameUIDemo` и нажмите Play. M открывает магазин, Escape закрывает магазин или открывает паузу. В магазине можно покупать предметы и читать причины отказа. В паузе доступны продолжение и перезапуск. Выход работает в собранной игре.

# Подключение

Добавьте префаб `Assets/Prefabs/UI/GameUI` в сцену, назначьте ему Run Bootstrap и Player Interaction. Магазин открывается вызовом `GameUI.OpenShop()`. Для сообщения о вращении вызовите `TryCompleteSpin(spinId, out var appliedResult)` и при успешном завершении передайте `appliedResult` в `ShowSpinResult`. Он содержит фактически потерянную кровь с учётом защиты и доступного остатка. Подпишитесь на `PauseChanged`, чтобы приостанавливать и продолжать визуальную анимацию. При завершении забега внешняя система должна отменить незавершённую анимацию.

Текущий RunState не хранит явную причину поражения; окно выводит причину по текущим ресурсам и времени. Для одновременных условий нужен отдельный контракт причины от системы забега. UI использует временный IMGUI, для окончательной читаемости и адаптации под экран требуется ручная проверка.
