# Основа забега

Откройте `Scenes/RunFoundation` и включите Play. В Console появятся значения из `Data/GameLoop/DefaultRunSettings`. Для сброса в Play выберите объект Run Bootstrap и команду **Reset Run** в меню компонента. Настройки можно менять в инспекторе; при сбросе создаётся новый снимок их текущих значений. Сцена не добавлена в настройки сборки.

`RunState` хранит данные независимо от Unity и уведомляет подписчиков событием `Changed` после сброса. Потребитель получает ссылку на состояние от `RunBootstrap`, читает его после инициализации и отписывается от события, когда оно ему больше не нужно. При создании состояния событие не вызывается для будущих подписчиков. Пока изменение состояния означает только сброс: отсчёт времени и правила игры не реализованы.

Код игрового цикла находится в `Scripts/GameLoop`, его Unity-компоненты и настройки — в `Scripts/GameLoop/Unity`, asset настроек — в `Data/GameLoop`, тесты — в `Tests/EditMode/GameLoop`. Сцены находятся в `Scenes`, префабы — в `Prefabs`, временные визуальные ресурсы — в `Art/Temporary`. Тесты запускаются через Unity Test Runner. Распределение будущих областей, границы систем и порядок совместной работы описаны в [TEAM_WORKFLOW.md](../../TEAM_WORKFLOW.md).
